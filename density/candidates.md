# Candidate optimizations: the global list

Every optimization considered for the density scheme, adopted or not, one line each. Details, evidence and raw data are in `candidates/<id>/`. "K" means the candidate depends on something only kernelets have (one address space, host-owned frames, a memory-safe kernel, cooperative kernels); "G" means a microVM stack could do it too, in which case the gain counts as a relative advantage only where the baseline cannot practically use it. Gains are multiplicative factors on the per-sandbox DRAM of the state they act on, against the baseline of `benchmark/README.md`. Evidence grades: **M** measured here, **L** published figure cited, **A** analytic derivation with stated assumptions, **U** unverified (does not count).

| id | candidate | K/G | acts on | gain alone | evidence | isolation effect | status |
|---|---|---|---|---|---|---|---|
| C01 | [Shared file pages](candidates/C01-shared-file-pages/): the host's page cache is mapped read-only into the kernelet window for public image content; no guest copy | K (G only with virtiofs DAX, which Firecracker lacks and Kata ships off by default) | `m_file` | removes 150–300 MiB per sandbox after a work burst | M, L | none: read-only pages of public content, the sharing the floor allows | adopted |
| C02 | [Host-owned frames, cooperative return](candidates/C02-cooperative-memory/): a kernelet returns free frames to the host at once; no balloon, no stranding | K | `m_kproc`, `m_file` churn | removes the 28 MiB stranded after reclaim and the reclaim's CPU cost | M, A | none | adopted |
| C03 | [Transparent host paging of idle kernelets](candidates/C03-host-paging/): the host evicts an idle kernelet's private frames to NVMe or compressed memory and faults them back on touch | G (KVM can swap guest memory too; a kernelet's page-in is a host page fault with no EPT) | `P_proc`, `m_kproc` in idle | idle DRAM from `P_proc` to ~0 at the 500 ms and 5 s tiers | M (wake read rate), A | none: frames stay host-owned, zeroed on reuse | adopted |
| C04 | [Lean kernelet fixed cost](candidates/C04-lean-fixed-cost/): CoW data template, small demand-backed thread stacks, no worker for a one-vCPU sandbox, 4 KiB metadata mapping | K | `m_fixed` | from the Blueprint's ~3–30 MiB (stacks dominate) to under 1 MiB | A | none | adopted; needs Blueprint changes |
| C05 | [Template cloning](candidates/C05-template-clone/): a kernelet is created as a copy-on-write clone of a pre-booted template with the agent runtime loaded | G (VM snapshots do this; a kernelet clone has no VMM or EPT to rebuild) | `m_boot`, initial `P_proc` | boot residue and runtime initialization shared; only written pages private | M (VM snapshot sharing measured), A | none: the template is one image's public state | adopted |
| C06 | [Idle and wake CPU cost](candidates/C06-idle-cpu/): no vCPU thread, no guest timer, no VMM restore for an idle kernelet | K | CPU | idle cost measured at 0.03 % of a core per idle VM (3 cores per 10,000); wake without a VMM restore | M | none | adopted, minor |
| C07 | [Compressed idle memory](candidates/C07-compression/): idle private pages compressed in DRAM before eviction | G | `P_proc` at the 50 ms tier | 2.6× measured on a resident kernel-plus-Python snapshot's pages | M | none | adopted for the 50 ms tier |
| C08 | Far memory (CXL, RDMA) for cold pages | G | idle DRAM | hardware not common; not counted | U | none | deferred |
| C09 | Content-based deduplication (KSM-like) across tenants | G | all | up to 2–3× on unikernel-style images in the literature | L | **weakens**: timing side channels on deduplicated pages | rejected by the isolation floor |
| C10 | Sharing written file pages across tenants | G | `m_file` | small | A | weakens: tenant-private content | rejected |
| C11 | Fewer, smaller guest kernel structures (kernel proper tuning: slab sizes, per-CPU pools for one vCPU) | K (same source both sides) | `m_kproc` | 2–5 MiB | A | none | folded into C04 |
| C12 | Per-vCPU right-sizing: one virtual CPU for an agent sandbox unless asked | G | `m_fixed`, CPU | avoids per-vCPU replicas, workers and pools | A | none | folded into C04 |
