# Enforcement: the checks

| # | property | check | kind |
|---|---|---|---|
| 1 | no crate reachable from `aster-kernelet` other than `kernelet-abi` depends on `ostd` or `endovisor`; `aster-kernelet` is `forbid(unsafe_code)`; no macro or derive the closure uses expands to `unsafe` | the `cargo metadata` closure query; a grep for the attribute; a checked-in list of every macro and proc-macro crate in the closure with a one-line justification | build |
| 2 | every "identical" facade item takes no host lock, retains no pointer, queues no closure; the cursor's escapes are exactly the listed ones | an executable test per item under lock-depth instrumentation and a pointer scan of host structures for window addresses | test |
| 3 | every writable object of a crate in the kernelet closure lies inside the data window and every other writable object outside it; no kernelet-closure object is in `.cpu_local` | the link-time ELF audit over the artifact OSDK produces, keyed by crate, one baseline per target | build |
| 4 | the arena's slot map produces only heap-window addresses; no host allocation lands in a window; no arena object is ever addressed through the linear map (an `RRef` buffer is a host object and is the stated exception) | assertions in the allocator, and check 2's pointer scan | test |
| 5 | only the endovisor implements `EndovisorServices` and `Exchangeable`; every service opens a host scope and performs the stack check | sealed supertraits; the single generic wrapper; both traits `unsafe`; a run-time test that every service leaves the caller's arena byte-count unchanged | compile + test |
| 6 | the host retains only kernelet-relative names plus the declared holders | the sealed `KerneletRelative` bound on host tables; every declared holder forgotten, never dropped, in [§4.7.4](../design/faults/destroy.md) | compile + test |
| 7 | the two windows are the only kernel-half mappings that differ between any two page tables | a test that walks two kernelets' page tables and diffs the kernel half | test |
| 8 | every virtio backend checks the owner of every frame it touches, before touching it, rings and indirect tables included, pins buffers for the life of a request and rings for the life of the queue | a fuzz harness that hands each backend chains and queue addresses pointing at another kernelet's frames, at host frames, at nothing, and that frees a buffer mid-request | test |
| 9 | every `impl Drop` in the kernelet crate carries `#[kernelet_drop]` | a lint | build |
| 10 | per-kernelet hot structures are 128-byte aligned; a per-kernelet counter never shares a line with another kernelet's | `const` assertions; the false-sharing microbenchmark | compile + test |
| 11 | the TCB does not grow silently | a reachability tool over the linked ELF with a recorded ceiling per crate | build |
| 12 | no kernelet draws more than the per-CPU reserve after its dying flag is set; no infallible allocation exceeds the cap; no cursor operation exceeds its reservation by more than three frames | debug-build assertions | dynamic |
| 13 | reclamation is complete | the create/destroy loop of tens of thousands of iterations, each leaving something behind on purpose (an open fd, a parked thread, an armed timer, an in-flight read, an RRef in flight, a passthrough DMA, a thread inside a kernel-mode fault, a space active on an idle CPU), with every free count back to its start and the owner sweep empty | dynamic |

**Not mechanically checkable, so nobody mistakes the table for a proof:** that host critical sections have bounded hold times; that the drain list of [§4.7.4](../design/faults/destroy.md) is complete; that the six handle kinds are the complete set of things a tenant needs; that unwinding through arbitrary kernelet frames leaves host structures consistent; that every infallible allocation site respects the cap; and that the checks themselves are correct, which for the link-time audit has been false twice on its first real input.
