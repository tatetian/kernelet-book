# The OSTD changes

**OSTD changes** the design needs, so that "no OSTD change" is never claimed: (1) name-based `Waker` and park/unpark by name; (2) a per-kernelet kernel page table whose top-level entry 500 is private, and `create_user_page_table` taking a parent; (3) `VmSpace::deactivate_on(cpus)` and `activate` under an interrupt guard; (4) `WaitQueue`, `Mutex`, `RwMutex` generic over their guardian; (5) the three host guardians, the sleepable locks and the cursor bumping the lock depth, and a kernelet guardian with its own guard and a dying poll in the spin loop; (6) `UserMode::execute` reading the pending-signal bit from the task, and a host handler on the return-to-user path; (7) `Task` growing the register state, the address-space reference, the reservation, the entry frame and the four attribution words, in a new `ostd::task::attribution` module; (8) `is_interrupt_context` and `is_local_enabled` exported; (9) a frame-reset primitive and a synchronous `rcu::synchronize()` that kicks idle CPUs; (10) the shim's `dealloc` error no longer aborting, and large heap allocations following the heap word; (11) `ArenaRoot<T>`; (12) the cursor's host-writing internals at the host heap word, its per-CPU lists draining by owner, and kernelet-owned deferred frame drops parked per owner; (13) `record_entry_frame`, `abandon_to_entry`, `abandon_from_tick`, about 50 lines of `unsafe` per architecture; (14) kernel preemption on the kernel-mode interrupt-return path; (15) the linker script's two window sections, the crate-name globs and the template load; (16) `Slab`, `HeapSlot` and the large-slot path generic over an address translation, so that a kernelet's slots are window addresses and a large slot never becomes a `Segment`; (17) an interrupt-stack-table stack and a handler for the double fault that rewrites the exception frame when the quiescence predicate holds; (18) PCIDs, *later and optional*: allocation and recycling of a tag per page table, all-context invalidation for every kernel-half non-Global range the tree unmaps without a flush today (vmalloc, kernel stacks), and a redefinition of a space's "active on" set as "may still cache my entries"; (19) the post-schedule handler activating a page table for every task, with a kernel-page-table activation that retires the per-CPU active-space pointer. Nineteen, of which (18) is not assumed anywhere; (9) touches the frame lifecycle `vostd` proves.
