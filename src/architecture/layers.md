# The layers and what each guarantees

| layer | mechanism | guarantees | enforced by |
|---|---|---|---|
| **1. Process** ([§4.1](../design/process/index.md)) | two per-kernelet windows in the kernel half; per-kernelet kernel page tables and a switch policy; the kernelet crate's writable sections placed in the data window by the linker script | every `static` of the kernel is per-kernelet; a pointer into a kernelet's memory dereferenced by a host task in thread context faults | the linker script; a link-time audit that no kernelet-crate writable object lies outside the window and no host object inside it |
| **2. Facade** ([§4.2](../design/facade/index.md)) | `aster-kernelet` depends on `kernelet-abi` under the name `ostd`; `kernelet-abi` re-exports, virtualizes, or omits each OSTD item | a kernelet cannot spell an ambient authority; the kernel's per-tenant statics and its `ostd::` paths are untouched | the crate graph; a `cargo metadata` closure check; `forbid(unsafe_code)` |
| **3. Memory** ([§4.3](../design/memory/index.md)) | arena in the heap window behind the allocator hooks; owner-tagged frames; two bands; per-CPU death reserve | the kernelet that runs out is the kernelet that overspent; nothing charged to a kernelet returns null | the allocator hooks; the owner array |
| **4. Threads** ([§4.4](../design/threads/index.md)) | Host-owned tasks, kernelet-named; one hierarchical preemptive scheduler; kernelet and host guardians; the worker at group-top priority; a stack check at every crossing | a kernelet lock never delays killing its kernelet; a kernelet cannot pin a CPU or exhaust a host stack | two guardian types; the tick; the facade denies interrupt control |
| **5. Devices** ([§4.5](../design/devices/index.md)) | virtio backends in the host, front-ends in the kernelet; descriptors checked by owner; passthrough under the IOMMU | a kernelet's I/O touches only its own frames; the host's device surface has a specification | the owner check per descriptor; the IOMMU |
| **6. Channels** ([§4.6](../design/channels/index.md)) | `RRef<T>` on host-owned buffers holding plain data; vsock semantics; receiver credit | a message never carries a pointer; a dead kernelet's messages are reclaimed | the `Exchangeable` bound, implemented only by the facade; the RRef table |
| **7. Faults** ([§4.7](../design/faults/index.md)) | unwind per thread; abandon at a quiescent point; destroy = drain, unmap, forget, release | panic, OOM, spin and kill each end one kernelet; reclamation needs no kernelet `Drop` | the quiescence predicate; the windows; the drain list |
