# What must be verified before this book is believed

Ordered by how much of the design each can sink.

0. **The frame-reset obligation.** State, and if possible prove as an extension of `vostd`, that a frame owned by a dead kernelet whose host references have been drained may have its metadata reset and be reissued. Until then [§4.7.4](../design/faults/destroy.md) step 8 is an argument. ([§4.7.4](../design/faults/destroy.md), [§3.5](../architecture/tcb.md))
1. **The window page table and the switch policy.** Confirm on the tree that a per-kernelet level-3 table at one top-level index can be installed under `create_user_page_table` (with the kernelet's kernel page table as the `'static`-equivalent parent) without breaking the shared-node rule OSTD asserts; that no OSTD path assumes the kernel half is identical in every page table; that a kernel-page-table activation that empties the per-CPU active-space pointer keeps `VmSpace::activate`'s early return and the "active on" set correct; and what the extra CR3 writes and the window flushes cost on same-kernelet and cross-kernelet switches. Only then decide whether PCIDs (change 18) are worth their coherence rewrite. **[unverified]** ([§4.1.2](../design/process/two-windows.md), [§4.1.3](../design/process/switch-policy.md))
2. **The linker-script placement and the template load.** Pin `-C symbol-mangling-version=v0` in OSDK. Confirm that OSDK's script can place `.kernelet.data` at `W_DATA` with an `AT()` load address and that the boot path loads the template bytes without mapping `W_DATA`; that under thin and full LTO every surviving static keeps a `.data.<v0 name>` section whose name carries its crate, internalized ones included; that the crate-name globs select exactly the kernelet closure's writable objects, that `.data.rel.ro.*` lands in the read-only segment, and that every writable object of a crate shared between the closure and the host is written only by the host at boot. Then rerun the audit with the inverted question. ([§4.1.4](../design/process/data-window.md), [§5.2](../implementation/checks.md) check 3)
3. **The manifest trick, end to end.** Build `aster-kernelet` with `ostd = { package = "kernelet-abi" }`; confirm that every name the kernel uses resolves to one of the three kinds, that no `ostd` macro re-exported through the facade expands to a real `ostd::` path, and that the same source still builds against the real `ostd`. ([§4.2.1](../design/facade/manifest-trick.md), [§4.2.3](../design/facade/item-kinds.md))
4. **Boot two kernelets and measure.** Dispatch, crossing, allocation, the kernel-mode fault path, the switch, and create/destroy on this design's kernel, against the booted prototype's numbers. ([§6.2](../evaluation/runtime.md))
5. **The virtio front-ends and backends.** Confirm the MMIO-transport front-ends build against a facade `IoMem` implementing `VmIo`, `VmIoOnce` and `HasPaddr`, and that no front-end reads the trap frame its interrupt callback receives. Fuzz each backend with chains, queue addresses and indirect tables into another kernelet's frames, host frames, unmapped frames, and pathological lengths, and with a buffer freed mid-request; confirm the owner check precedes every touch, that pinning defers the free, and that a completion after the kernelet's death still writes the used ring into the kernelet's still-owned frames while its job is refused ([§4.5.2](../design/devices/backend.md) step 4, [§4.8.1](../design/walkthroughs.md#read)). ([§4.5.1](../design/devices/why-virtio.md), [§4.5.2](../design/devices/backend.md), [§5.2](../implementation/checks.md) check 8)
6. **`RRef` under the accounting.** Confirm that no crate but the facade can implement `Exchangeable` (the seal of [§4.6.2](../design/channels/rref.md)) and that a kernelet crate cannot obtain a second name for a buffer by any safe means; that the channel account is conserved across transfers and refunded at death; that a dead owner's in-flight buffers are released exactly once; and measure create/send/release against 104/177/94. ([§4.6](../design/channels/index.md))
7. **The window-addressed slab, the hard band, and `#[alloc_error_handler]` in `no_std`.** Make `Slab`, `HeapSlot` and the large-slot path generic over an address translation and confirm the intrusive free list, `which_slab` and the dealloc range check work on window addresses, that a large slot in the arena never reaches `Segment::from_raw`, and that a free inside a host scope routes on the task's kernelet; then, as in Alternative A, confirm the arena serves the hard-band trip before the shim sees a null, and that a host allocation can never land in a window. ([§4.1.5](../design/process/heap-window.md), [§4.3.3](../design/memory/bands.md), [§5.2](../implementation/checks.md) check 4)
8. **The abandon primitive and the quiescent points, under concurrency**, including the double-fault handler's frame rewrite for an overflow at a quiescent point, its halt otherwise, and a kill taken beneath a trap frame. ([§4.4.5](../design/threads/stack-check.md), [§4.7.1](../design/faults/tiers.md))
9. **The destroy drain list**, including deactivation of spaces active on idle CPUs, the RRef rows, the passthrough IOMMU domain, and the unmap-before-release ordering; then the adversarial create/destroy loop. ([§4.7.4](../design/faults/destroy.md))
10. **The thread-state relocation and kernel preemption.** Move the register protocol into the task; add the kernel-mode preemption point; confirm a `while true {}` in a syscall is descheduled by the tick without the 100 ms budget. ([§4.4.1](../design/threads/tasks.md), [§4.4.3](../design/threads/scheduler.md))
11. **The `LocalIrqDisabled` alias.** Confirm that no kernelet-side site that disables interrupts today relies on excluding an interrupt handler that survives the move of all deferred work to the worker; the timer and softirq callers are the ones to read. ([§4.4.4](../design/threads/guardians.md))
12. **The lock split and the lock depth**, including migration of the depth with a parked task and the cursor's bumps. ([§4.4.4](../design/threads/guardians.md), [§4.3.4](../design/memory/address-spaces.md))
13. **The size cap, growable collections, reservations, and the 221 lock-held allocating sections** counted in the tree for Alternative A, re-audited under this design's predicate. ([§4.3.3](../design/memory/bands.md))
14. **The page cache**: frame state out of `MetaSlot`, the `xarray` rewrite, the shrinker, and chunked copy-up. ([§7.1](losses.md), item 8)
15. **Kernelet fork.** Define the precondition (every thread at the syscall boundary or in user mode, no in-flight I/O, no `RRef` in flight), copy the two windows and the host objects, and measure against a snapshot restore. ([§4.1.5](../design/process/heap-window.md))
16. **The two TCB levers**, and a reachability measurement of the backends. ([§3.5](../architecture/tcb.md))
17. **Passthrough**: the IOMMU domain per kernelet, interrupt remapping to the kernelet's CPU, and teardown ordering at destroy. ([§4.5.4](../design/devices/passthrough.md))
18. **The component system, `ktest` and OSDK** after the split, and how a `#[ktest]` in `aster-kernelet` obtains a kernelet to run in. ([§4.2.5](../design/facade/split.md))
19. **Frame gifting over vsock**: only after the copying path works, with the mapping-count precondition. ([§4.6.4](../design/channels/vsock.md))
20. **The control plane.** This book does not describe the interface through which a kernelet runtime in host user space creates a kernelet, hands it its grant, budget, devices and storage extents, and destroys it, nor what the kernelet runtime itself looks like; `KerneletCtl` is held by the endovisor and nothing says how host user space reaches it. Design it, and say which of the checks of [§5.2](../implementation/checks.md) cover it. ([§0.1](../introduction/index.md#what-a-kernelet-is), [§4.2.4](../design/facade/services.md))
