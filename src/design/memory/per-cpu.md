# Per-CPU caches and the floor

No per-CPU structure may hold a kernelet's memory: the heap's per-CPU slot cache becomes a per-(CPU, kernelet) magazine of one slab per size class (36 KiB per pair), keyed by kernelet slot *and generation*, charged up front as `affinity × 36 KiB` so that the set of CPUs a kernelet has run on is not observable through its own bill, never reaped while the kernelet lives (a model measured that an idle reaper drains nothing or storms), and drained at destroy. The frame allocator's per-CPU caches are not used for kernelet frames. The floor per kernelet is one 2 MiB grain plus the data window (a few pages) plus `affinity × 36 KiB` plus 512 KiB of host-owned kernel stack per thread; a small kernelet uses under one per cent of its first grain, so the grain is the floor and not the working set.
