# Frames and the owner tag

User frames, page-cache frames, page-table nodes and DMA buffers are `Frame<()>` and `Segment<()>` a kernelet holds by handle and OSTD addresses through the linear map; they come from the **frame dispatcher**, the host's implementation of OSTD's frame-allocator hook ([§4.3.1](arena.md)). A kernelet obtains one only from `alloc_frames` against its grant, which reserves the count first and allocates under the reservation, so a fallible request that finds the grant empty returns `ENOMEM`. The owner array answers, in one load, "does this frame belong to the calling kernelet", and every host path that takes a frame from a kernelet asks it: the virtio backends for every descriptor ([§4.5.2](../devices/backend.md)), `bind_address_space` for the page-table root ([§4.3.4](address-spaces.md)), the passthrough IOMMU mapping ([§4.5.4](../devices/passthrough.md)), and the frame dispatcher on every free.
