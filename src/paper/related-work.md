# Related Work

**Language-based isolation.** SPIN loaded type-safe extensions into the kernel [7]; J-Kernel gave Java domains revocable capabilities and argued that recovery, not access control, is the hard part [13]. Singularity ran untrusted software-isolated processes at one privilege level in one address space with typed channels [8]. RedLeaf brought the model to Rust: private heaps, a shared heap of pointer-free exchangeable objects, and domain recovery that unwinds to a trampoline and frees by domain identifier without running destructors [9]. Asterinas Kernelets' exchangeable buffers, heap split and stack-abandoning kill are RedLeaf's, applied to an adversarial instance that is a complete kernel. Theseus tracks each component's state by ownership so that components can be swapped [14]; Asterinas Kernelets does the opposite, forgetting and releasing by region, and borrows only its name for an instance.

**Kernels compiled against a facade.** Rump kernels compile an unmodified NetBSD kernel against a small hypercall interface, one tree building both, and run it in a process or in kernel mode [10]; User-Mode Linux [15] and Drawbridge [16] likewise run a kernel or library OS against a narrow host interface. That is API virtualization for portability, and Asterinas Kernelets' first two contributions are its idea turned to isolating adversarial tenants: the cut is made at a framework whose API is the caller's entire authority, and instances share one ring-0 image. The name Cells was used by Andrus et al. for virtual phones on a shared Linux kernel [17], which partitions the kernel's views as containers do.

**Virtualization.** Xen replaced privileged instructions with hypercalls in a guest written for hardware [18]; virtio standardized the paravirtual device interface [11]. Asterinas Kernelets keeps virtio and removes the trap beneath it, because the kernel was never written for hardware. MicroVMs [2] and unikernels [19] minimize the guest and the device model but keep the hardware boundary; gVisor [20] intercepts every system call into a user-space kernel. seL4 [21] verifies a microkernel that isolates by address space and capability; Asterinas Kernelets keeps capabilities at the host boundary but runs tenant kernels in one address space.
