# Acronyms

Acronyms used without further gloss: **TCB** (trusted computing base), **IPI** (inter-processor interrupt), **RCU** (read-copy-update deferred reclamation), **DMA**, **IOMMU**, **TLB**, **CR3** (the x86 page-table root register), **PML4** (the top-level x86-64 page table), **PCID** (per-page-table TLB tag), **XSAVE area** (the x86 FPU and vector register save block), **vsock** (the `AF_VSOCK` socket family Linux uses between a VM and its host), **POD** (plain old data: a type every bit pattern of which is valid), **TOCTOU** (time-of-check to time-of-use).
