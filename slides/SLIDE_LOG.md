# 星绽 Kernelets 汇报页：迭代记录

一页 16:9 SVG，给政府/主管部门领导汇报用。素材、数字口径与流程见
`/tmp/.../scratchpad/slide-prompt.md`（本轮任务的 prompt）。

## 版面

中心是技术架构图与预期成效带；四角按「为什么重要 → 为什么现在不行 →
我们怎么做 → 凭什么是我们 → 能落到哪里」的动线环绕：左上业界趋势，
左下现有方案的局限，右上技术先进性与自主可控，右下产业落地。

## 数字口径（写死的规则）

- **内存密度 ≈2×**：技术对等条件下（双方均支持把空闲沙箱换出内存）的上界，
  256 核服务器。来源 `git show density:density/bounds.md` 的 parity 行
  （上界 1.8–2.0×，当前设计方案达 1.4–1.6×）。**不用** 5.2–9.3× 那个
  对比"常驻保温"做法的数字。
- **I/O 固定开销 ↓3–10×**：轮询模式下与用户态 VMM 设备后端相比，取
  `src/blueprint/design/zero-copy-io.md` 区间 3–50× 的保守段。脚注必须
  保留"独占 CPU 核的轮询后端可达同一量级，但需长期占用一个核"这句，
  它是这个数字公平性的前提。
- 两个数字都带 ※，指向底部"模型估算，原型尚未实测"。

### v2 / v3：第一轮评审后的修改

评审提出 6 项严重、8 项重要的内容问题与 12 项视觉问题。已改：

**内容（严重）**
1. **`≈2×` 是"任何方案的理论上界"，不是本方案的成效。** 来源文档里，对等技术
   条件下 256 核的上界是 1.8–2.0×，而本方案达到的是 1.4–1.6×；128 核上本方案
   与基线持平。大字改为 **1.4–1.6×**，把 2× 降为卡内小字"任何方案的理论上界"，
   脚注补上 128 核与 DAX 两种收敛到 1× 的条件。**这一条与"密度取 2.0×"的原始
   指示相悖，改动原因见最终说明，可一键改回。**
2. **I/O 的 3–10× 只对最弱基线成立。** 脚注补全三条对比：对用户态 VMM 后端
   3–50×（取保守值）、对内核态 vhost 约 2–30×、**中断模式下与 vhost 大致相当**。
3. **零拷贝的硬前提缺失。** 脚注加"以每沙箱独立网卡队列、块设备直通裸分区为
   前提"，并注明主机侧支撑代码尚在开发中。
4. **"已完成机器证明"超前。** 上游自述为 ongoing。全页改为"内存管理核心模块
   已完成机器证明，验证范围持续扩大"，并从 3 处减到 1 处（OSTD 条与右上卡各一，
   指标卡那处换成"可嵌套"）。
5. **没说"用本方案 = 宿主内核换成星绽"。** 架构图加"宿主内核（星绽）· 内含
   endovisor"框；右下卡加"部署前提：以星绽作为宿主内核"。
6. **逃逸事件归因有偏差。** 该事件是容器与编排层逃逸，不是硬件虚拟化失效；若
   放在"微虚拟机的局限"旁边，逻辑上反而支持微虚拟机。已改为明写"经容器与编排
   层配置逃逸"，并把微虚拟机的问题重新定位为**代价**而非安全性（左下卡加一句
   "容器不够隔离；微虚拟机隔离够了，但代价太高"）。

**内容（重要）**
- 主张句"把隔离边界从硬件搬到语言"在安全语境下读感是"拆掉了硬件保护"，改为
  "同一个地址空间，多个安全内核"，并加副标题"用户态到内核的硬件边界完全保留；
  被去掉的只是虚拟机监控器这一层"。
- 三痛点与三成效原本对不上（"不能嵌套"无回应）。第三张指标卡改为**可嵌套 ·
  虚拟机内可直接运行**，正好是本方案最干净的胜利。
- "抢占制高点"原来的论据是"投稿顶会"；改用已发表的 USENIX ATC 2025 论文。
- 自主可控补上政府受众必问的两点：已支持 RISC-V 等指令集；隔离性由机器证明
  兜底，不依赖对境外编译器的信任。
- 右下卡加一行路线（论文已发表 → 原型与实测 → 2027 场景试点）。
- 逃逸事件加 ※ 与出处（Hugging Face 官方复盘与 OpenAI 公开披露）。

**视觉**
- 标题渐变改纯青（渐变末端在深底上对比度仅 2.95:1，且 PowerPoint 对文字渐变
  支持差）。
- **全文件消除一切 opacity**：PowerPoint 常忽略 `stop-opacity`/`fill-opacity`，
  会把半透明色块渲成高饱和实色。所有颜色预先与底色合成为不透明 hex。
- 脚注 13px→14.5px、`#5C6180`→`#9AA0BE`（对比度 3.1:1 → 7.2:1）；图内小字
  同样提亮。
- 五个区块加 ①–⑤ 角标，解决叙事顺序与自然动线冲突。
- 中心主张 27px→32px，与两侧眉标对齐。
- 去掉 3 处重复标签（"一个沙箱一个"×3 并入行标题）与两条多余竖虚线。
- 右下两个场景框由 104 收到 96，底部留白从 7px 增到约 24px；左侧两卡正文重新
  断行以填满行长。
- 宿主内核框改用蓝色系，与租户框区分。
